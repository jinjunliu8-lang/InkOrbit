# InkOrbit（墨环）

> Draw directly on AI answers.

InkOrbit 是一个纯本地 Chromium 浏览器扩展，用数位笔或鼠标直接在 ChatGPT 的回答上圈画和批注。悬浮工具围绕主球展开，像一圈随手可用的“墨环”。

## 功能

- 页面右侧提供可拖动、自动吸边的 AssistiveTouch 式批注悬浮球。
- 兼容 ChatGPT 新旧两种回答结构，网页调整后仍能识别回答并显示悬浮球。
- 点击悬浮球会自动选择当前屏幕中的回答，并展开半圆形气泡工具菜单。
- 进入批注后画布覆盖整个可见网页区；滚动到页面其他位置可以继续书写，笔迹随网页滚动。
- 全页面始终只有 committed/live 两个 Canvas；实时书写采用增量绘制和自适应分辨率。
- 触控板高频事件按屏幕刷新帧合并，滚动时自动使用轻量分辨率，停下后恢复高清笔迹。
- 滚动坐标实时读取当前祖先链，兼容回答加载后才产生滚动、嵌套滚动和滚动容器替换；已完成笔迹与正在书写的笔迹同帧同步。
- 新笔画增量加入空间索引，橡皮手势结束时才统一提交；长对话不会反复扫描未变化的回答正文。
- 数位笔落笔立即书写，停顿和慢写不会自动切换为拖页；用触控板滚动即可继续写。
- 数位笔仍按在画布上时，触控板双指滚动、鼠标滚轮或另一根手指都可同时移动页面，不会结束批注。
- 钢笔支持 Pointer Events 压感，提供黑、红、蓝三色。
- 数位笔丢失指针捕获或漏报抬笔时自动结束上一笔，下一次落笔可以继续书写；快速短笔画保留抬笔位置。
- 黄色荧光笔、整笔触橡皮、撤销、重做与可撤销清空。
- 一级悬浮菜单提供红色垃圾桶按钮，一键清空当前对话所有回答的笔迹，并可一次撤销恢复。
- 批注模式下，手指、鼠标中键、笔侧键或“空格 + 鼠标拖动”均可直接移动网页。
- 笔迹以矢量数据保存在 IndexedDB；刷新或重新进入对话后自动恢复。
- 非批注模式不会挡住文字选择、链接、代码复制等原有交互。
- 不请求网络权限，不使用 OpenAI API，不上传回答或批注。

## 本地安装

1. 安装依赖并构建：

   ```bash
   npm install
   npm run build
   ```

2. 在 Chrome 或 Edge 打开扩展管理页。
3. 开启“开发者模式”。
4. 选择“加载已解压的扩展”，然后选中本项目的 `dist` 目录。
5. 打开或刷新 `https://chatgpt.com/`，等待回答生成完成后点击页面边缘的蓝白色画笔悬浮球。

悬浮球可以拖到任意位置，松手后会吸附在左右两侧。点击钢笔、荧光笔或橡皮两次可以展开颜色、粗细和清空等二级气泡。书写时无需点击“完成”就能移动页面：使用触控板双指、鼠标滚轮、手指、鼠标中键、笔侧键或空格加鼠标拖动。触控板和手指还可在笔尖按住期间独立滚动；松开后当前画笔保持不变，可以立即继续写。数位笔停留仍作为书写，不再自动触发长按拖页。

代码修改后运行 `npm run build`，再到扩展管理页点击刷新按钮。

## 数位板说明

扩展使用浏览器标准 `PointerEvent` 接收 `pressure`。只要数位板驱动能向 Chrome/Edge 提供压感事件即可使用；鼠标会自动使用固定压力。普通笔侧键用于立即拖页；驱动报告为专用橡皮端的事件仍作为橡皮处理。

## 数据与兼容性

批注按“对话 ID + 回答 ID + 回答内容摘要”保存，并在浏览器空闲时合并写入 IndexedDB；数据库连接会在当前页面复用，写入事务完整完成后才视为保存成功。退出批注或页面隐藏时会立即刷新待保存数据。0.2.x 的回答局部坐标会自动转换为页面坐标，0.3.x 页面坐标数据可直接继续使用。
